# 世界临界点 Demo

一个全球同服、持续运行的国家资源投放与统一模拟 Demo。

在线体验：<https://lcpaper.github.io/world-critical-point-demo/>

## 本地运行

直接打开 `index.html`，或在目录中运行：

```bash
python3 -m http.server 8080
```

访问 <http://localhost:8080>。

## 主要功能

- 177 个国家区域的可交互世界地图
- 完整大整数资源显示，核心规则不使用除法
- 五类物资、单次 1–100 份、30 秒冷却
- 自动世界时间、资源变化、事件进程和国家整合
- 投放动画、地图脉冲、新闻与历史时间线
- Debug 调速、任意加资源、触发事件、结局演示与重置

详细规则见 [PRD.md](./PRD.md)。

## 说明

这是无后端的产品演示，不包含真实充值、账户、多玩家同步或真实政治评价。所有世界状态均为架空模拟。
